02. VIRTUAL MACHINE MANAGEMENT
================================================================================================================

COMMAND                 EXAMPLE                         DESCRIPTION                         IMPACT
----------------------------------------------------------------------------------------------------------------
VM List                 sudo hvmcli vm list             List virtual machines                Read-only
VM Details              sudo hvmcli vm list --details   Display detailed VM information     Read-only
VM by Name              sudo hvmcli vm list --name test-vm01
                                                        Display a specific VM                Read-only
VM Start                sudo hvmcli vm start --name test-vm01
                                                        Start a stopped VM                  Service change
VM Stop                 sudo hvmcli vm stop --name test-vm01
                                                        Stop a running VM                   Service change
VM Force Stop           sudo hvmcli vm stop --name test-vm01 --force
                                                        Force-stop a VM                     High risk
VM Restart              sudo hvmcli vm restart --name test-vm01
                                                        Restart a VM                        Service change
VM Reboot               sudo hvmcli vm reboot --name test-vm01
                                                        Request guest reboot                Service change

OPERATIONAL VALIDATION
----------------------------------------------------------------------------------------------------------------
1. List VMs.
2. Identify the target VM.
3. Check its current power state.
4. Perform the required operation only after workload approval.
5. Verify the final VM state.

13. COMMAND EXECUTION RISK CLASSIFICATION
================================================================================================================

LEVEL                   DESCRIPTION                     EXAMPLE
----------------------------------------------------------------------------------------------------------------
LOW                     Read-only commands              Version, Help, List
MEDIUM                  Diagnostic commands             Events, Health, Validation
HIGH                    Configuration changes           DNS, NTP, Network changes
CRITICAL                Service-impacting operations     Host reboot, VM force-stop, OS update

PRODUCTION EXECUTION RULES
----------------------------------------------------------------------------------------------------------------
1. Verify command syntax before execution.
2. Take approved backups before major changes.
3. Confirm workload impact.
4. Verify storage and cluster health.
5. Maintain iLO/console access.
6. Execute configuration changes during approved maintenance windows.
7. Record command output and execution timestamp.
8. Validate the environment after every change.
